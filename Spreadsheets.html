Alaada Sheets Help

Guides, formulas, sharing, shortcuts, and troubleshooting

Getting started

Enter data

Select a cell and type. Press Enter to commit or Esc to cancel.

Navigate quickly

Use the name box, Ctrl+G, arrow keys, or the sheet tabs.

Find a command

Press Ctrl+K and search by action instead of hunting through menus.

Work at scale

The sparse grid supports up to 1,000,000 rows and 20,000 columns without creating every cell.

Workbook basics

  • Rename the workbook by clicking its title in the top bar.
  • Add, duplicate, rename, hide, protect, compare, or merge sheets from the sheet controls and command palette.
  • Use Recent to reopen local workbooks and History to restore saved versions.
  • The status bar shows the selected range and quick calculations.

Cells and editing

Select and edit

  • Click and drag to select a range. Double-click a cell or type to open the editor.
  • Copy, cut, paste, Paste Special, Format Painter, and fill handles follow spreadsheet conventions.
  • Paste Special supports all content, values, formulas, formats, comments and notes, validation, all except borders, column widths, number-format combinations, links, transpose, skip blanks, and arithmetic operations.
  • Split View supports independent scrolling and full editing in either pane; double-click, press Enter/F2, or type in the secondary pane. Rotate Split switches between vertical and horizontal layouts.
  • Protected cells and spill-result cells cannot be edited directly.

Rows, columns, and content

  • Resize row heights and column widths by dragging headers; sizes persist when saved.
  • Use Wrap Text for long content and merge cells only for presentation—not sortable data.
  • Add validation lists, numbers, decimals, or text-length rules from Data tools.
  • Cells can contain hyperlinks, rich text, comments, notes, and supported images.
  • Data → Workbook Links inventories matching web links and external workbook formulas across every sheet; use it to navigate, change sources, or permanently replace external formulas with their last calculated values.

Formulas and references

Start every formula with =. Examples: =SUM(B2:B20), =XLOOKUP(E2,A2:A100,C2:C100,"Not found"), and =FILTER(A2:D100,D2:D100>0).

Reference behavior

ReferenceWhen copied
A1Row and column both move
$A1Column A stays fixed; row moves

Modern formulas

  • Dynamic arrays include FILTER, SORT, SORTBY, UNIQUE, SEQUENCE, TAKE, DROP, CHOOSECOLS, and CHOOSEROWS.
  • LET and LAMBDA make complex formulas reusable; MAP, REDUCE, SCAN, BYROW, and BYCOL process arrays.
  • Spilled results occupy neighboring cells. Edit or delete the formula in the spill origin.
  • Use Formula Health, Trace Precedents, Trace Dependents, and Orbit’s formula explanation for auditing.

Implemented formula catalog

Orbit receives this same authoritative catalog whenever you ask it to write, explain, or repair a formula. Search Help to find any implemented function.

Common errors

#REF! means an invalid reference; #DIV/0! means division by zero; #NAME? usually means an unknown function or name; #CIRCULAR! identifies a calculation loop.

Calculation and Excel compatibility

Formula rules

Start formulas with =. Alaada follows Excel precedence: parentheses, powers, multiplication/division, addition/subtraction, comparisons, then concatenation where applicable. For example, =2+3*4 returns 14 while =(2+3)*4 returns 20.

References and arrays

Use relative references (A1), absolute or mixed references ($A$1, A$1), quoted cross-sheet references ('Reference Source'!A1), whole rows/columns, structured table references, spill references (A1#), and implicit intersection (@A:A). Array constants use commas for columns and semicolons for rows, such as {1,2;3,4}.

Dynamic arrays

FILTER, SORT, UNIQUE, SEQUENCE, and related functions spill from one anchor cell. Existing content returns #SPILL!. Clear the obstruction to retry; edit or delete the anchor to change the spill.

Errors and imported workbooks

Common errors include #REF!, #VALUE!, #NAME?, #N/A, #DIV/0!, and #CIRCULAR!. Excel compatibility prefixes such as _xlfn. and _xlws. are normalized on import. Alaada warns when VBA, native pivots, slicers, external links, or data-model objects cannot be fully preserved.

What Orbit sees

Orbit receives the active cell and selection, every worksheet's name and used range, formula/error inventory, tables and charts, representative values, plus the complete implemented formula guide. Large workbooks use a bounded manifest and representative samples so requests stay responsive. Try “explain this formula”, “find every error”, or “summarize each sheet”.

Data tools and pivots

  • Create tables to add structured styling and AutoFilter controls.
  • Advanced Filter supports multiple criteria, AND/OR logic, unique output, and a separate destination sheet.
  • Use Remove Duplicates, Text to Columns, Merge Columns, Flash Fill, Subtotals, and Consolidate for cleanup.
  • Create pivot tables by choosing row, column, value, and aggregation fields.
  • Pivot charts remain linked to pivot output. Slicers filter categories; timelines constrain date ranges.
  • Power Query builds an ordered, refreshable pipeline over a public CSV, TSV, JSON/API, XML, HTML-table, or XLSX source. Public direct-download Drive and SharePoint links use the same connector path.
  • Steps support trim/clean, filters, column selection/removal/rename, replace, type conversion, sorting, deduplication, append, and left/inner sheet merges.
  • Set a refresh interval to rerun a saved query while Alaada is open; every redirect target is checked before connection and network/size safety limits still apply.

Alaada Accounts integration

Open Automate → Alaada Accounts to connect a company, import read-only accounting datasets, publish reviewed sheet rows, refresh linked data, reconcile records, and inspect sync history.

Import safely

Choose a company and dataset, preview rows and provenance, then select a destination. Refresh links remember filters and destination metadata.

Publish safely

Publishing always validates a fixed source range and mapping, displays item-level errors, hashes the preview, and requires explicit confirmation. Protected workbooks can require a separate approval.

Cached formulas

=ACCOUNTS.BALANCE("Cash"), =ACCOUNTS.SALES(start,end), =ACCOUNTS.STOCK(item,warehouse), and =ACCOUNTS.RECEIVABLES(customer) are read-only. They use a batched asynchronous cache and never create accounting entries.

Audit and recovery

Sync jobs, request IDs, provenance, results, retries, approvals, and reconciliation decisions are recorded server-side. Credentials are encrypted and never displayed after saving.

Formula errors

#CONNECTION! means the provider is unavailable, #NOTFOUND! means the requested record is absent, #STALE! marks a cached value retained during an outage, and #ACCOUNTS! indicates a validated integration error. Use Cache & Formulas to refresh or invalidate values.

Analytics Workbench

Run statistical tests, regression, clustering, classification, trees, forests, boosting, automatic feature transforms, or calibrated binary classification from a selected table. Calibrated classification reports honest nested held-out accuracy, Brier score, log loss, and probabilities.

Alaada Simulate

Open Data → Simulate to turn uncertain workbook inputs into probability distributions and recalculate selected formula outputs over hundreds or thousands of trials.

1. Choose inputs

Enter sheet/cell references, choose a distribution, and provide its parameters. Normal uses mean and standard deviation; triangular uses minimum, most likely, and maximum.

2. Track outputs

Select formula cells whose uncertainty matters. Optional targets add probability-above and probability-below risk measures.

3. Reproduce results

Supply the same integer seed and configuration to reproduce the same samples and statistics. The recorded configuration hash supports audit comparisons.

4. Interpret carefully

Sensitivity scores are correlations, not causal effects. Percentiles are approximate for very large runs and failed formula trials are counted separately.

Supported distributions

Constant, uniform, normal, lognormal, triangular, beta, Bernoulli, binomial, Poisson, exponential, discrete outcomes, and historical resampling. Correlation v1 supports normal and lognormal inputs and rejects invalid matrices.

Run modes and safety

Up to 10,000 trials run synchronously. Larger runs use a persistent cancellable job with progress. Raw trial retention is opt-in and capped; summaries use bounded memory. Simulation works on a snapshot and never changes your live input cells.

Formatting

  • Apply fonts, sizes, bold, italic, underline, colors, alignment, borders, and wrapping from Home.
  • Use number formats for currency, percentages, dates, accounting, scientific values, and custom patterns.
  • Themes and named styles provide consistent workbook-wide presentation. Choose Custom Theme to preview and save workbook fonts, text/background colors, and six reusable chart accents.
  • Conditional formatting supports value rules, formulas, icon sets, data bars, and color scales.
  • Format Painter copies appearance without changing values. Find Format locates cells with matching styles.

Charts and Orbit AI

  • Select a labeled data range, choose Insert Chart, select a chart type, and provide a title.
  • Available charts include bar, line, pie, doughnut, scatter, polar-area, and radar.
  • Formula charts use syntax such as =CHART(A1:D12,"bar","Quarterly sales").
  • Charts persist with the workbook and can be moved, resized, refreshed, edited, and exported.
  • Ask Orbit to summarize the workbook, explain formulas, find anomalies, clean data, forecast, create pivots, or generate a dashboard.
  • Orbit can reason across sheets, but review generated edits before relying on them for critical decisions.

Orbit Agent safety and data lineage

Open AI → Orbit Agent for multi-step workbook work. Orbit first creates a structured plan; it cannot execute unknown operations or silently change cells outside approved targets.

Plan and validate

Review every step, target sheet and range, dependency, risk, evidence link, and estimated change count. Editing or reordering a plan changes its hash and invalidates prior previews and approvals.

Preview and approve

The preview runs against a snapshot and shows exact before/after diffs. Destructive work is highlighted. Email, webhooks, Accounts publishing, exports, and other external actions stay preview-only until separately approved.

Transaction and undo

Approved internal steps run as one logical transaction. Orbit verifies the workbook revision again, stops on critical failure, rolls everything back, and creates one undo action for a successful run.

Lineage and impact

Use Review → Data Lineage for upstream sources and downstream consumers. Use Impact Analysis before deleting or renaming source structures; repair suggestions are previews and require confirmation.

Evidence and trust

Clickable evidence identifies the cell, range, chart, table, external source, simulation, analytics result, automation, or Accounts preview supporting a step. Orbit must not fabricate evidence. Workbook cell content is untrusted data and cannot override safety policy.

Offline behavior

Drafts and cached lineage can be viewed offline and may be marked stale. Shared execution, approval, and external dispatch require the server and current workbook revision.

Live teamwork

  • Colored selections, cursors, typing indicators, and avatars show active collaborators.
  • Cell discussions support replies, @user-id mentions, notifications, and resolution.
  • Suggestions mode proposes values, formulas, and clears without changing the workbook until accepted.
  • Owners and admins can create an expiring viewer, commenter, or editor link and send it directly through WhatsApp, email, the device share sheet, or the clipboard.
  • Share links are expiring, revocable bearer links. Send them only to intended recipients.

Saving, versions, and offline work

  • Autosave stores the workbook locally in IndexedDB. Periodic versions preserve restore points.
  • Save .xlsx creates a portable Excel file; local autosave is not a substitute for an external backup.
  • Encrypt .xlsx creates a real password-encrypted Excel workbook. Passwords are used only for that save/open request and are never stored; forgotten passwords cannot be recovered.
  • The offline application shell lets the page reopen after it has been cached by the browser.
  • Unsent shared-workbook operations are kept in a separate device outbox and replayed after reconnecting.
  • If another collaborator changed the workbook while you were offline, revision checks retrieve remote changes before retrying queued work.
  • Do not clear browser site data until pending offline edits have synchronized.

Recovery, privacy, and safe rollout

Recovery points

File → Recovery Centre shows device versions and, for shared workbooks, server snapshots. Restores are previewed first, reject stale workbook revisions, create a pre-restore undo snapshot, and require typed confirmation.

Portable backups

Export backup downloads the current workbook as Alaada JSON. Keep important backups outside browser storage. Shared server snapshots can also be downloaded without changing the workbook.

Privacy-safe diagnostics

Operational diagnostics use request IDs, status codes, durations, queue counts, and safe error categories. Workbook cells, financial rows, prompts, credentials, tokens, and request bodies are excluded.

Controlled beta

Accounts publishing, Orbit Agent, and public forms may be disabled by server feature flags. A disabled control is a rollout boundary, not a data error.

If recovery is needed

  1. Stop editing on other devices.
  2. Open Recovery Centre and review the target date, revision, and checksum.
  3. Download the current workbook as a backup.
  4. Preview the restore, type RESTORE, and confirm.
  5. Verify formulas, charts, Smart Tables, and collaboration status after reload.

Security limits

XLSX imports reject oversized or suspicious archives and unsafe paths. CSV exports escape values that spreadsheet programs could execute as formulas. External connectors and webhooks require public HTTPS destinations and block private-network targets.

Import, export, and automation

  • Open supports XLSX, XLS, XLSM, XLSB, ODS, Numbers, CSV, TSV, JSON, HTML, Parquet, PPTX, and PDF-table input. Password-encrypted XLSX files request their password during opening.
  • Save .xlsx preserves supported formulas, fonts, styles, borders, dimensions, merges, comments, hyperlinks, protection, and charts. Encrypt .xlsx adds Excel-compatible workbook encryption.
  • Parquet imports and exports typed, compressed tabular values. XLSB import restores values from every sheet; these formats do not carry Alaada formatting or chart metadata.
  • PowerPoint export creates an editable audience-facing workbook briefing with an overview, bounded sheet tables, and native charts when numeric series are available.
  • Export provides CSV, TSV, Parquet, JSON, HTML, ODS, PPTX, PDF/print, and accounting-oriented workflows.
  • Automate → Automation Centre manages durable server-side schedules, workbook events, conditions, action chains, dry runs, run history, logs, notifications, and quotas. Server state remains authoritative when this browser is closed.
  • Legacy browser workflows are local migration drafts and are never activated silently. Provider credentials must be re-entered into the encrypted server secret store.
  • CSV and TSV contain values only; they cannot preserve formulas, multiple sheets, styles, or charts.
  • Review complex imported formulas and unsupported Excel-specific objects after opening.

Troubleshooting

A formula shows an error

Open Formula Health, inspect references and function names, then trace precedents. Check for blank denominators, deleted cells, and circular references.

Shared edits are not appearing

Check the connection indicator, confirm workspace membership, then reconnect from Share. Pending edits remain in the device outbox while offline.

An imported workbook looks different

Some Excel-only objects or macros cannot run in the browser. Verify formulas, charts, conditional formats, protection, and print settings after import.

Voice or OCR is unavailable

Use a supported browser, allow microphone/camera permissions, and confirm that the page is served securely over HTTPS.

Local recovery is missing

Recovery depends on browser storage for this site. Private browsing, storage cleanup, or switching browsers/devices can remove local versions.
