The Journey

From idea to ecosystem.

November 2025 — Founded
Alaada is born in Kolkata
Started as a solo experiment: could one developer build a focused AI product from India that competes globally? The answer became Alaada.
November 2025 — First Product
Web Analyser launches
Shipped as a fully real audit tool — no fake metrics, no paywalled results. Paste a URL, get the truth.
1 January 2026 — Growing Suite
Orbit AI launches
Deep-reasoning AI with live web search, file analysis, voice output, and a memory system powered by the browser itself. No Supabase, no server state — pure user ownership.
March 2026 — Sheets
Alaada Sheets launches
20+ formulas, AI NLP commands, and exports to Excel, SQL, JSON, and Tally XML. Built for Indian businesses from day one.
1 August 2026 — Business Platform
Alaada Accounts launches
A connected accounting and business operations platform goes live with double-entry accounting, sales, purchases, inventory, GST, CRM, reports, automation, bulk imports and AI-assisted workflows.
2026 — Connected Ecosystem
Building the ecosystem
Connecting Orbit AI, Alaada Accounts, Web Analyser and Alaada Sheets under one platform, with a shared design language and cross-product intelligence.

How We Build

Design principles we refuse to compromise on.

🧱
One job, done right
No feature overload. If it doesn't make the core job better, it doesn't ship.
🌐
Browser-first
No installs. No app stores. Works anywhere with a browser — because that's everywhere.
🔐
User owns their data
Data handling should be clear, secure and transparent. Users should understand what is stored, where it is stored and how it is used.
📦
Ship, then perfect
A real tool in the world beats a perfect tool on a whiteboard. We iterate in public.
💬
Plain language, always
No jargon walls. Every result, score, and suggestion is written for a human, not a spec sheet.
🇮🇳
Proudly Indian
Built in Kolkata. Priced for India. Designed for the world. Local trust, global ambition.
